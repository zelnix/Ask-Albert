# One-Screen Dashboard — Route and Data Mapping

The updated developer instructions (`Ask_Albert_One_Screen_Dashboard_Developer_Instructions-3.md`) govern this layout. Home is a nine-card summary. **Every card opens a substantive `dashboard-*` result before its specialist links.** Each subsection displays actual published/owner-scoped results or an explicit loading, stale, unavailable or error state before the specialist link. Unsupported capabilities show WAIT or Needs changes, never a silent coin substitution. Illustrative smart-money/institutional panel values are withheld, not presented as observed data. No new provider, exchange orders or automatic strategy revision are introduced.

## Truth and ownership boundaries

- `paper/overview` now resolves the owner’s **account collection**, independently of saved strategy rows. Zero wallets is shown only after that read succeeds and returns zero accounts. If any owner wallet is absent from the strategy roll-up, aggregate cash/equity/positions/P&L are withheld instead of showing a partial total. Protected/deployable cash is shown only when all account values and marks are complete. A read-only owner ledger reconciliation returns `MATCH`, `MISMATCH` or `UNAVAILABLE` rather than assuming health. The wallet selector still opens the individual owner-scoped account dashboard.
- `paper/overview.asOf` is a ledger **read time**, not a provider market-mark timestamp. Wallet valuation remains unavailable when an asset lacks a current mark.
- The BTC scenario band is a **historical** range; the forward forecast model is a separate source. The performance ticker only calls measured predictive skill validated when a completed, current evaluation supports it. Missing/stale evaluation says `Not validated` or `Evaluation unavailable`.
- The seven ticker metrics remain independent buttons opening source/evidence explanations; their detail links lead through the consolidated view. Expanding a chart is a separate full-viewport action; its follow-up link also leads through consolidated detail. Original Home card body/title/CTA goes to its consolidated view. Selected wallet/strategy IDs are retained only in the browser session and rechecked against owner-scoped API results.
- Home requests owner/state/market reads plus the three existing whale/network/sentiment feeds for its data-rich flows card; supplementary detail-only sources load on navigation. Independent source statuses do not inherit the dashboard run's freshness. The header/hamburger is outside the section, including during missing dashboard market runs.
- No automated backend/frontend checks, browser captures or fixtures for this change have been run; propose explicit checks and wait for the user’s permission.
